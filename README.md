# Рыцарь против Дракона

Браузерная версия консольной игры на Python. Проект сохраняет идею ООП: в `game.js` есть классы `Dragon`, `Player` и `Game`.

## Как запустить на компьютере
1. Скачайте или распакуйте проект.
2. Откройте `index.html` в браузере.

## Как опубликовать игру через GitHub Pages
1. Войдите в GitHub и нажмите **New repository**.
2. Назовите репозиторий, например `dragon-knight-game`, и создайте его.
3. Нажмите **Add file → Upload files** и загрузите `index.html`, `style.css`, `game.js` и `README.md` (можно загрузить содержимое распакованной папки).
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**.
6. В разделе **Build and deployment** выберите **Deploy from a branch**.
7. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
8. Подождите минуту-другую. В разделе Pages появится ссылка вида `https://ВАШ-ЛОГИН.github.io/dragon-knight-game/`.

## Важно
GitHub Pages публикует статические сайты. Поэтому логика игры перенесена из Python в JavaScript — браузер может запускать её без отдельного сервера. Это одиночная игра: для совместной игры по сети с другими игроками понадобится серверная часть.
